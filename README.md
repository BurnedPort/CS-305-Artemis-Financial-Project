CS 305 Portfolio Reflection

In this project, I worked with a fictional client, Artemis Financial, a financial services company that required improvements to the security of its software application. The primary issue the company wanted addressed was the presence of vulnerabilities in their system, including insecure communication and outdated dependencies. The goal was to refactor the application to follow secure coding practices and ensure that sensitive financial data was protected during transmission.

One area I performed well in was implementing secure communication using HTTPS and addressing dependency vulnerabilities identified through automated scanning tools. I used OWASP Dependency-Check to identify outdated and vulnerable libraries and worked to mitigate those risks. Coding securely is critical because it protects sensitive information, prevents exploitation, and reduces the likelihood of data breaches. Strong software security adds value to a company by maintaining customer trust, protecting financial assets, and ensuring compliance with security standards.

One of the more challenging aspects of this project was analyzing the vulnerability scan results and distinguishing between legitimate issues and false positives. However, this process was also valuable because it improved my ability to interpret security reports and make informed decisions about which vulnerabilities required immediate attention.

To increase layers of security, I implemented HTTPS for secure communication and addressed vulnerable dependencies. In the future, I would continue using tools such as OWASP Dependency-Check, static analysis tools, and penetration testing techniques to assess vulnerabilities and determine appropriate mitigation strategies.

I ensured the application remained both functional and secure by testing it after implementing changes and verifying that HTTPS was correctly configured. After refactoring, I reran vulnerability scans to confirm that existing vulnerabilities were resolved and that no new issues were introduced.

Throughout this project, I used tools and practices such as OWASP Dependency-Check, secure coding principles, encryption via HTTPS, and configuration management. These will be highly valuable in future work, especially in cybersecurity roles focused on application security.

For future employers, I would showcase this project as an example of my ability to identify vulnerabilities, refactor code to improve security, and validate those improvements using industry-standard tools. This demonstrates both my understanding of secure software development and my ability to apply it in practice.
